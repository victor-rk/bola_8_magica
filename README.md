# 🔮 Bola 8 Mágica

Programa em Python que simula uma Bola 8 Mágica: o usuário faz uma pergunta e recebe uma resposta aleatória, com animação de carregamento no terminal.

Criado para praticar os módulos nativos `random`, `time` e `sys`, além de repetição, funções e entrada de dados.

## Funcionalidades

- Resposta aleatória a cada pergunta
- Animação de carregamento no terminal
- Validação de pergunta vazia
- Encerramento ao digitar `Sair` (sem diferenciar maiúsculas de minúsculas)

## Tecnologias

- Python 3.6 ou superior
- `random`: seleção aleatória da resposta
- `time`: tempo da animação
- `sys`: escrita direta na saída do terminal

## Como executar

```bash
git clone https://github.com/victor-rk/bola_8_magica.git
cd bola_8_magica
python app.py
```

## Como utilizar

1. Execute o programa
2. Digite uma pergunta e pressione `Enter`
3. Aguarde a animação e leia a resposta
4. Faça outra pergunta ou digite `Sair` para encerrar
