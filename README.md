# 🔮 Bola 8 Mágica

Um programa desenvolvido em Python que simula uma Bola 8 Mágica, respondendo às perguntas do usuário com respostas aleatórias.

O projeto foi criado com o objetivo de praticar o uso dos módulos nativos `random`, `time` e `sys`, além de trabalhar com estruturas de repetição, funções e entrada de dados.

## Funcionalidades

- Respostas aleatórias para cada pergunta
- Animação de carregamento no terminal
- Validação de perguntas vazias
- Encerramento do programa ao digitar `Sair`
- Exibição da pergunta e da resposta correspondente

## Tecnologias utilizadas

- **Python 3.12**
- `random` - seleção aleatória de respostas
- `time` - controle do tempo da animação
- `sys` - manipulação da saída no terminal

## Como executar

**1.** Clone este repositório:

```bash
git clone https://github.com/victor-rk/bola_8_magica.git
```

**2.** Acesse a pasta do projeto:

```bash
cd bola-8-magica
```

**3.** Execute o programa:

```bash
python app.py
```

## Como utilizar

1. Execute o programa
2. Digite uma pergunta e pressione `Enter`
3. Aguarde a animação de carregamento
4. Leia a resposta gerada aleatoriamente
5. Digite outra pergunta para continuar ou `Sair` para encerrar
